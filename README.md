# Daten statt Bauchgefühl – Übungsdateien

Übungsdateien zum Buch **„Daten statt Bauchgefühl – Produktionsprozesse analysieren mit Power Query, Power Pivot und lokaler KI auf dem Minicomputer“** von Andreas Wittmann.

## Herunterladen

1. Klicken Sie rechts auf **Releases** und öffnen Sie die neueste Fassung.
2. Laden Sie die Datei `Uebungsdaten_Daten_statt_Bauchgefuehl.zip` herunter.
3. Entpacken Sie die ZIP-Datei vollständig in einen Ordner Ihrer Wahl, zum Beispiel `C:\Buch\Uebungsdaten\`.
4. Lesen Sie zuerst die Datei `LIESMICH.txt` im Paket.

## Inhalt

| Ordner | Inhalt | Dateien |
|---|---|---|
| 01_Stammdaten | Anlagen, Produkte mit Spezifikation, Sollwerte, Statuscodes, Stillstandsgründe | 1 |
| 02_Schichtbuch | eine Arbeitsmappe je Monat 2025 | 12 |
| 03_ERP_Export | eine CSV-Datei je Monat, ab Juli in anderem Format | 12 |
| 04_Maschinendaten | eine CSV-Datei je Tag, Werte je Viertelstunde | 365 |
| 05_Labor | Laborjournal, BET-Export und 13 Monatsdateien des Granulometers | 15 |
| 06_Muehlenprotokoll | ein Mahllauf je Los | 1 |
| 07_Belegung | Raster Tag × Anlage | 1 |
| 08_Anweisungen | erfundene Arbeitsanweisung für Kapitel 15 | 1 |
| 09_Skripte | Python-Skripte für Kapitel 16 | 5 |
| – | `LIESMICH.txt` | 1 |

## Hinweis

Alle Daten beschreiben das Jahr 2025 der erfundenen Lindentäler Pulvertechnik GmbH. Betrieb, Produkte, Personen und Zahlen sind erfunden. Die Dateien sind mit Absicht so unordentlich wie echte Betriebsdaten – bitte nicht von Hand korrigieren.
